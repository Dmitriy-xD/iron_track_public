# IRONTRACK — дневник тренировок (Telegram Mini App)

Фронтенд приложения IRONTRACK: дневник силовых тренировок, который работает внутри Telegram.
Подходы записываются за пару касаний. Приложение считает тоннаж, рекорды и e1RM, подсказывает вес на следующий подход и показывает нагрузку по мышцам за неделю.

Живая версия: бот [@irontrack_gym_bot](https://t.me/irontrack_gym_bot).

## Стек
- **React 18** — интерфейс, только функциональные компоненты и хуки;
- **TypeScript** в строгом режиме;
- **Vite** — сборка и dev-сервер;
- **Vitest** — тесты расчётов;
- **Telegram WebApp API** — вход по `initData`, кнопка «Назад», вибрация, оплата звёздами;
- без UI-библиотек: дизайн, анимации, графики и барабан выбора веса написаны вручную (CSS + SVG).

Сервер (PHP + MySQL) в этот репозиторий не входит. Фронтенд обращается к нему через `src/data/api.ts`.

## Запуск
```bash
npm install
npm run dev        # dev-сервер на http://localhost:5173
npm test           # тесты
npm run build      # проверка типов + сборка в dist/
```

## Как устроены данные
`StoreProvider` (`src/data/store.tsx`) один раз загружает данные пользователя и кладёт их в React Context.
Любой экран берёт их через `useStore()`: `db.sessions`, `db.sets`, `db.plan` и действия `addSet`, `startSession`, `finishSession`.
Изменения сначала применяются локально, поэтому интерфейс отвечает сразу, а потом уходят на сервер.

Расчёты (`src/analytics`) — обычные функции без React. Их легко тестировать отдельно: `forecast.test.ts`, `starterPlan.test.ts`, `analytics.test.ts`.
